## 결정: 저장 호환 = 기존 id 유지 + 새 id + 화면 번호 분리
- 저장 `st = { id: 별 }` 키는 그대로. 새 스테이지 id = `x-5`, `x-6` (2~4장), 배열에서 보스(id `x-4`) 앞에 둠 → 보스는 여전히 `stages[stages.length-1]` (chapterUnlocked, gear.clearedSets, backfill 그대로 동작).
- 화면 번호: `stages.js` 가 챕터 안 순서로 `s.no = 'ch-(i+1)'` 를 붙이고 `stageNo(id)` 제공. 사용처: 원정 지도 노드·정보 패널, 출전 배너, 클리어/패배 화면, 마을 결과 팝업, 해금 목록, 고유 출처 문구(gear.uqSrcText), 전직 조건 문구.
- `stageUnlocked`: 이미 별이 있는 스테이지는 항상 열림 → 예전 보스 클리어 저장에서 새 x-6 를 안 깼다고 보스가 다시 잠기지 않음. 다음 장 해금은 보스 별 기준이라 그대로.
