## 해금

- 주소만 바꿔(`?stage=1-3&run=1&hard=1`) 잠긴 하드로 들어오면 `G.hard=false` → 노말로 진행. 클리어 저장 때 하드가 잠겨 있으면(다른 탭 등) 노말 기록으로 대체.

## 저장 (`save.hst = { 스테이지 id: 별 }`)
- 노말 `st` 와 같은 id, 따로 저장 → 노말 진행 영향 없음. `progress.clean` 이 유효 id·1~3만 남김(옛 저장엔 없음 → `{}`), `merge` 는 스테이지별 최댓값.
- Supabase: `hd3d_progress.data` 는 jsonb 통째(크기 64KB 제한만, 키 검사 없음) → 스키마 변경 없음. 동기화는 clean → merge → 업로드라 `hst` 가 보존됨(node 테스트로 JSON 왕복 확인).
- 알려진 작은 점: 캐시된 **옛 클라이언트**는 `hst` 를 모름 → 옛 탭에서 저장하면 그 기기 저장에서 hst 가 빠질 수 있음(클라우드에 있으면 새 클라이언트 병합 = 최댓값으로 복구). Pages 갱신 후 새로고침하면 해결.
