# 히어로 디펜스 3D

Three.js(로컬 번들, CDN 없음)로 만든 쿼터뷰 3D 웹 디펜스 게임.

**플레이:** https://hyunjk11.github.io/hero-defense-3d/

- 영웅 선택: 궁수(장거리 연사, 스킬 화살비) / 마법사(광역+둔화, 스킬 메테오) / 전사(근접 탱커 베기, 스킬 회오리 베기)
- 길 놓기·바리케이드 건설 → 적은 최단 경로로 코어를 향해 이동, 막히면 바리케이드를 공격
- 소형/일반/탱커/비행 적, 5웨이브마다 보스, 코어 HP 0이면 게임 오버
- 강화: 공격력·공격 속도·사거리·스킬·바리케이드 체력
- 블룸, 그림자, 낮/밤, 파티클, 데미지 숫자, 코인 연출, 보스 화면 흔들림

조작: 좌클릭 이동/건설 · WASD 이동 · Q 스킬 · 우클릭 드래그 회전 · 휠 확대 · 1/2/3 건설 도구 · Space 웨이브 시작
